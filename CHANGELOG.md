# Changelog

All notable changes to this project will be documented here.
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] — 2025-XX-XX

### Added
- Initial public release
- Automatic `.xpm` → `.xpm.wav` preview generation
- Exact, substring, and fuzzy matching strategies
- Interactive resolver dialog with audio preview and playback stop
- Persistent last-used folder (`mpc_config.txt`)
- Colour-coded activity log with status pill
- Modern dark UI theme (rounded buttons, card layout, tonal palette)
- Skip scanning abort support — cancel mid-run at any time
- Re-run safety: skips programs that already have previews
